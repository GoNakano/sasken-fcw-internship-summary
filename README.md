# 海外インターン：前方衝突警告（FCW）の組み込みボード実装

立命館大学の海外インターンシップで、インド・ベンガルールのSasken Technologiesに約4週間参加しました（2026年8月17日〜9月11日、AI/MLトラック）。  
学生5名のチームで、車載向けの前方衝突警告（Forward Collision Warning、FCW）を、TIの評価ボード上で動かすまで開発しました。

このリポジトリは、プロジェクトの概要と自分の担当をまとめたものです。ソースコードはチームのリポジトリで管理しており、ここには含めていません。社外秘に当たる資料・コード・数値も載せていません。

## 何を作ったか

提供された走行映像（H.264動画）から前方の車両を検出し、衝突までの時間（TTC）を推定して、危険なときに警告を出すシステムです。  
まずPCのPythonで試作し、その処理をCに移して、TI TDA4VM（J721E EVM）の物体検出アプリに組み込みました。

```text
H.264動画
  → ハードウェアデコーダー（NV12形式の画像に変換）
  → SSDによる車両検出（ボード上のAI推論）
  → 前方の領域（ROI）に絞り込み
  → 同じ車両の追跡（IoU）
  → 衝突までの時間（TTC）の推定
  → 警告（画面の赤枠表示・音声アラート）
```

## 成果

- 2026年9月9日に、評価ボード上で車両検出・警告の赤枠表示・音声アラートまで動く実機デモが完成しました。
- 2026年9月10日に、チーム5名で英語の成果発表（35分）を行いました。
- 追跡とTTCの精度は十分ではなく、製品レベルの精度評価は終わっていません。

## 自分が担当したこと

チームで分担・協力しながら、主に次の作業に関わりました。

- Saskenのラボにある Ubuntu PCへの、ボード用Linux＋RTOS SDKのセットアップ（もう1人のメンバーと担当）
- Ubuntuでのビルドと、評価ボードへの転送・実行・動作確認
- メンバーのブランチを自分のブランチへ統合（Git）
- H.264動画の入力処理とFCW処理（C）の、ボードの物体検出アプリへの統合。コードの編集には生成AI（Claude Code・Codex）を使い、ビルドと実機での確認は自分で行いました
- 成果発表では、評価ボードのセットアップ、個人の貢献、まとめを担当しました（担当分のスライドは生成AIで作成）

## 途中で起きた問題

- 入力の動画にデコードエラーがあり、動画を再エンコードして検証しました。
- 動画の解像度（1280×720）と、アプリの設定・表示用のバッファの大きさが合わず、表示が崩れました。設定とバッファを解像度に合わせて直しました。
